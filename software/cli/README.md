# serial-hw-keybridge CLI

This directory contains the command-line interface (CLI) for the serial-hw-keybridge project. The CLI is designed to facilitate controlled keystroke injection and aid in boot-level debugging.

## Overview

The CLI provides a user-friendly interface for interacting with the hardware and firmware components of the serial-hw-keybridge project. It allows users to send commands, configure settings, and monitor the status of the connected devices.

## Purpose

The primary purpose of the CLI is to enable developers and users to easily control and test the functionality of the serial-hw-keybridge hardware. It serves as a tool for debugging and development, streamlining the process of keystroke injection.
