# serial-hw-keybridge GUI

This directory contains the graphical user interface (GUI) components for the serial-hw-keybridge project. The GUI is designed to facilitate user interaction with the hardware and firmware, providing a user-friendly way to control keystroke injection and monitor system status.

## Overview

The GUI is built using Python and is intended to run on various platforms. It communicates with the hardware to send commands and receive feedback, enabling users to perform boot-level debugging efficiently.

## Structure

- **src/**: Contains the main application code for the GUI.
- **requirements.txt**: Lists the dependencies required to run the GUI application.
- **README.md**: This file provides an overview of the GUI and its usage.

## Usage

To run the GUI, ensure that all dependencies are installed. You can install the required packages using the following command:

```
pip install -r requirements.txt
```

After installing the dependencies, you can start the GUI by running the main application script located in the `src/` directory.
