# serial-hw-keybridge

This directory contains firmware-related files for the ESP32-S3 platform. The firmware is designed to facilitate controlled keystroke injection for debugging purposes.

## Overview

The ESP32-S3 firmware is built to support the following features:
- Controlled keystroke injection
- Integration with various microcontroller stacks
- Boot-level debugging capabilities

## Supported Platforms

- ESP32-S3

## Build Notes

To build the firmware for the ESP32-S3, ensure you have the necessary development environment set up, including the required libraries and tools. Follow the instructions in the `platformio.ini` file for configuration details.

## Usage

Refer to the main source files in the `src` directory for implementation details and usage examples.
