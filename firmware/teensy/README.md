# serial-hw-keybridge Firmware for Teensy

This directory contains the firmware specific to the Teensy microcontroller platform for the serial-hw-keybridge project. 

## Overview

The Teensy firmware is designed to facilitate controlled keystroke injection for boot-level debugging. It leverages the capabilities of the Teensy microcontroller to interact with various systems effectively.

## Supported Platforms

- Teensy 3.x
- Teensy 4.x

## Build Notes

To build the firmware for the Teensy platform, ensure you have the PlatformIO IDE installed. The `platformio.ini` file in this directory contains the necessary configuration for building and uploading the firmware to the Teensy device.

## Usage

1. Open the project in PlatformIO.
2. Connect your Teensy device to your computer.
3. Select the appropriate environment in PlatformIO.
4. Build and upload the firmware to your Teensy device.
