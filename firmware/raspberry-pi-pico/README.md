# serial-hw-keybridge
This directory contains firmware-related files for the Raspberry Pi Pico platform.

## Overview
The Raspberry Pi Pico firmware is designed to facilitate controlled keystroke injection for debugging purposes. This firmware leverages the capabilities of the Raspberry Pi Pico microcontroller to interact with various systems at a low level.

## Supported Platforms
- Raspberry Pi Pico

## Build Notes
To build the firmware for the Raspberry Pi Pico, ensure you have the necessary development environment set up, including the required toolchain and libraries. Refer to the `CMakeLists.txt` for build instructions and dependencies.
