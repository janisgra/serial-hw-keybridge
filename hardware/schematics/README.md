# serial-hw-keybridge Hardware Schematics Overview

This directory contains the schematics for the serial-hw-keybridge project. It provides an overview of the hardware variants used in the project, including Teensy, ESP32-S3, and Raspberry Pi. 

## Contents

- **Diagrams**: Placeholder wiring diagrams for the hardware connections.
- **Photos**: Optional build photos that illustrate the assembly and connections of the hardware components.

Please refer to the respective README files in the firmware and hardware directories for more detailed information on each platform and hardware variant.
