# serial-hw-keybridge Hardware Overview

This directory contains hardware-related documentation for the serial-hw-keybridge project. It includes information about the different hardware variants supported, such as Teensy, ESP32-S3, and Raspberry Pi.

## Hardware Variants

- **Teensy**: A powerful microcontroller platform suitable for various applications.
- **ESP32-S3**: A versatile microcontroller with integrated Wi-Fi and Bluetooth capabilities.
- **Raspberry Pi**: A popular single-board computer that can be used for a wide range of projects.
